# Final Project - Drive Test Visualization

## 📌 Overview

This project is a web-based system for visualizing wireless signal data (drive test) using 3D models and interactive maps.
It allows users to analyze signal performance in a building environment.

---

## 🛠 Tech Stack

* Frontend: React (Vite)
* Backend: Flask
* 3D Model: GLB format
* Visualization: Web-based dashboard

---

## ⚙️ Installation

### 1. Clone repository

```
git clone <your-repo-url>
```

### 2. Install frontend

```
cd drive-test
npm install
npm run dev
```

### 3. Run backend

```
cd backend
python app.py
```

---

## 📊 Features

* Upload and visualize 3D building models (.glb)
* Design the Transmitter for Indoor environment
* Analyze signal strength data
* Display error metrics (MAE, RMSE)
* Interactive dashboard
